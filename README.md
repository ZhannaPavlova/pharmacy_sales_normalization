## Проект: Нормализация и анализ данных аптечных продаж (май 2026)
## Структура репозитория:
'/data/raw/' - архив исходных "грязных" выгрузок.
'/data/dictionaries/' - спроективанные реляционные справочники ('dict_clients' ,'dict_products','dict_dates','dict_addresses').
'/analytics/' - очищенные таблицы и аналитические отчеты.
'/docs/' - схема бизнес-процессов, документация и JSON-контракты.
## Решенные задачи:
ETL и чистка данных: Устранены баги кодировки (UTF-8), исправлены сдвиги столбцов с помощью экранирования кавычками, ликвидированы пропуски ('NULL') и аномалии в адресах.
Проектирование реляционной БД (MDS): Плоские таблицы нормализованы и разделены на независимые сущности с выделением Первичных и Внешних ключей (ID).
Интеграции (REST API & JSON): Разработаны и отваледированы (через JSONLint) сложные JSON-контракты с вложенными массивами товаров ('itmes []') для передачи заказов методом 'POST'.
Моделирование процессов (BPMN 2.0): Спроектирована схема обработки заказа интернет-аптеки ('order_process_bpmn.png') с валидацией адреса доставки и проверкой остатков.
